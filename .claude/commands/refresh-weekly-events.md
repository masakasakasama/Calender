---

「今週のおすすめイベント」を最新化します。Gemini など外部AI APIは使いません。
あなた自身の WebSearch でリアルな開催情報を集めて JSON を書き換えます。

手順:

1. WebSearch で東京・横浜・千葉・埼玉と近郊の日帰り圏を調べ、これから約1〜2週間に実際に開催されるイベント、祭り、期間限定の催しを集める。
2. 候補は必ず優先度順に並べる。基本順位は以下。
   1. その週末または特定日しか開催されない大型・話題イベント
   2. その週末だけの祭り、花火、マーケット、特別公開、ライブ系
   3. 数日〜1週間程度の短期イベント
   4. 数週間〜数か月の長期開催イベント、常設に近い企画展
3. 長期開催イベントを、その週末に始まるという理由だけで「初出」「開幕」「今しかない」ように強調しない。開催期間をそのまま表示し、週末限定候補より下位に置く。長期開催でも最終週など本当に期限が迫る場合のみ優先度を上げる。
4. 同じ優先度なら、話題性、デート向き度、アクセス、季節性、無料または価格妥当性の順で比較する。
5. 取得元が不確かな候補は載せない。開催日変更・中止も公式情報で確認する。
6. 表示画像は主催者、会場、自治体・公式観光サイト、公式プレスページが提供する画像URLだけを使う。公式画像を確認できない候補は非表示または削除する。ストックフォト、Unsplash、画像検索結果、無関係な代替画像、AI生成画像は禁止。
7. 変更があれば関連する JSON を更新し、main に commit して push する。
8. ユーザーへの通知は、実質的な変更がある場合のみ行い、commit SHA と短い変更内容を伝える。何も変わらなければ通知しない。
